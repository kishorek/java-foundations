1. Your first Java program

A program is a set of instructions for a computer. Java code is the way we write those instructions in a form Java tools can understand.

class Main { public static void main(String[] args) { System.out.println("Hello, world!"); } }

This small program prints a message. It may look full of strange words and symbols, but each part has a job. We will unpack them one by one.

Analogy: a recipe
A recipe has a title, a set of instructions, and a starting point where you begin cooking. A Java program also groups instructions, and Java starts running an ordinary beginner program from its main method.

What happens when it runs?

1
Java finds the starting point

For this example, that is main.

2
It executes instructions in order

The print instruction runs when Java reaches it.

3
You see the output

The message appears in the console, which is the text area used to show program output.

2. What does System.out.println mean?

This is a command you will see in almost every early Java tutorial. It displays information in the console and then moves to a new line.

System.out.println("Hello!");

Break it into pieces

1
System

A built in Java class that provides useful system features.

2
.out

The standard output stream. Think of it as the program's usual place to send text, often shown in a console.

3
.println(...)

A method that prints the value inside the parentheses, then starts a new line.

4
;

The semicolon marks the end of this Java statement.

Analogy: an announcement system
System.out is like the speaker system. println is the action of making an announcement. The text inside the parentheses is the announcement itself.

println versus print

println
System.out.println("One"); System.out.println("Two");
One
Two

Each call ends on a new line.

print
System.out.print("One "); System.out.print("Two");
One Two

The next output continues on the same line.

Choose what Java prints

System.out.println("Red"); System.out.println("Blue");
Output will appear here.
One important distinction: println displays a value. It is not the same as return, which sends a result back from a method to the code that called it.

3. Text, numbers and quotation marks

Java treats text and numbers differently. Quotation marks tell Java that something is text rather than a name or a number.

Text: a String
System.out.println("42");

Output: 42

The value is text because it is inside double quotes.

Number: an int
System.out.println(42);

Output: 42

The value is a whole number that Java can use in arithmetic.

The printed output can look identical even when the underlying values have different types. That difference matters when you calculate, compare, or pass values to methods.

Try text and numbers

Output will appear here.

A String is text surrounded by double quotes in Java source code.

Joining text with +

System.out.println("Score: " + 95);
Score: 95

When a String is involved, + can join text and a value to make one displayed message.

Quotation mark rule: Java source code uses double quotes for String text, like "Hello". A character literal uses single quotes, like 'A'. These are different types.

4. Symbols and syntax

Programming languages have grammar. In Java, small symbols can change what code means, and missing one can stop the program from compiling.

Semicolon ;

Ends many statements.

int age = 14;
Curly braces { }

Mark the beginning and end of a block of code.

if (age > 10) { System.out.println("Hi"); }
Parentheses ( )

Hold method inputs or conditions.

println("Hello")
Double quotes " "

Surround String text.

"Hello"
Dot .

Accesses a member, such as a method or field.

System.out
Comments //

Comments are notes, not instructions

// This line explains the next instruction System.out.println("Welcome");

Use comments to explain why something is done, not to repeat code that already says what it does.

Common beginner error: forgetting a semicolon after a statement, or leaving a quote or curly brace unclosed. The compiler usually reports an error, though the reported line may be near rather than exactly at the cause.

5. What are class and main?

For the examples in these tutorials, two structures are especially important: a class groups code, and main is where execution begins.

class Main { // class begins public static void main(String[] args) { // main begins System.out.println("Hi"); } // main ends } // class ends
1
class Main

Declares a class named Main. A class is a container for related Java code.

2
public static void main(String[] args)

This is the standard entry point for a simple Java application. For now, learn to recognise it rather than memorising every keyword immediately.

3
Nested braces

The first opening brace begins the class. The next begins main. Each needs a matching closing brace.

Simple mental model: the class is the folder, main is the starting page, and statements inside main are the instructions followed from top to bottom.

What do the main keywords mean?

public

The Java runtime must be able to access this entry point.

static

Allows this method to be called on the class without creating an object first.

void

This method does not return a value.

String[] args

A place for text arguments supplied when the program starts. You can ignore it in the first exercises.

Does every file have to be named Main.java?

Not always. In a simple example with a non-public class called Main, the file name can vary. When a class is declared public, the source file name normally must match that public class name, such as Main.java for public class Main.

6. Running code and understanding errors

The interactive examples here simulate output so you can learn the ideas. To run actual Java code, you need a Java Development Kit (JDK) and a place to write and execute the program.

Editor

Where you write the source code, for example a simple text editor or an IDE.

Compiler and runtime

The JDK includes tools to compile Java source code and run Java programs.

Typical beginner workflow

1
Write the source

Save the code in a file such as Main.java.

2
Compile it

The Java compiler checks the source and produces bytecode. Syntax mistakes are reported as compile errors.

3
Run it

The Java runtime executes the compiled program and the output appears in the console.

Debugging habit: read the first compiler error carefully. Check the line shown, then also inspect the line immediately above it. One missing symbol can cause several follow-on errors.

Important words you will meet

Compile

Check and translate Java source into a form the runtime can execute.

Runtime

The period when a program is actually running.

Console

A text area where a program can display output and sometimes receive input.

Syntax

The grammar rules that determine whether code is written correctly.
