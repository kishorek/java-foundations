Lesson 1

Imagine a labelled storage box

A variable is a named place where your program keeps a piece of information.

📦

Think of a variable as a labelled box. The label tells you what the box is for, and the item inside is the value. A box labelled age might contain 18. A box labelled name might contain "Maya".

Watch the box change

The variable is named age. Change its value and see what the program's box contains.

Label · variable name
age
The name we use in our code
Inside the box · value
18
A whole number
Java example
int age = 18;
Read it from left to right: int means a whole number, age is the box's label, and = 18 puts the value 18 into that box. The semicolon marks the end of this Java instruction.
Lesson 2

Not every value belongs in every box

Java uses data types to know what kind of information a variable can hold.

🧺

Think of a kitchen. A cup is good for water, a jar can hold rice, and a tray can hold eggs. You could try putting soup in an egg tray, but that is not a great plan. Data types are Java's way of choosing a suitable container.

🫘

byte

Very small whole numbers from −128 to 127, useful when saving memory in large collections of small values.

Example: 100
📏

short

Small whole numbers from −32,768 to 32,767, bigger than byte but smaller than int.

Example: 25000
🔢

int

Whole numbers such as a person's age or the number of books. This is the usual default for whole numbers.

Example: 18
🏦

long

Very large whole numbers, such as a population count. Large long literals usually end with L.

Example: 9000000000L
🪙

float

Decimal numbers using less precision than double. A decimal literal usually needs an f suffix.

Example: 3.14f
💧

double

Decimal numbers with more precision than float, often used for measurements and calculations.

Example: 172.5
🔤

String

Text, such as a name or a city. Text goes inside double quotes.

Example: "Maya"
🔠

char

One single character, written inside single quotes.

Example: 'M'
✅

boolean

A yes or no style value, represented by true or false.

Example: true
🧮

long

Whole numbers that may be much larger than the usual int range.

Example: 9000000000L

Choose a container

Select a value and predict which Java type is a good fit.

Common mix up: 'M' is a char, while "Maya" is a String. Single quotes are for one character, and double quotes are for text.
Lesson 3

Declare it, then give it a value

Java statements often follow a predictable pattern, so you can read them like a simple recipe.

Three useful words

String name = "Maya"; int books = 12; double price = 99.50;

Type tells Java what kind of value to expect. Name is the label you choose. Value is the information stored inside it.

Try changing the value

Choose a type, give the variable a name, and enter a value. The example updates instantly.

Your Java statement
int score = 100;
A variable name should start with a letter, underscore, or dollar sign, and it cannot contain spaces.
Important: Java is case sensitive, so score and Score are different names. Also, String begins with a capital S, while int and boolean begin with lowercase letters.
