1. What is an array?

An array stores multiple values of the same type under one variable name. Each value has a numbered position called an index.

Analogy: a row of numbered lockers
Each locker has a number, and each locker holds one item. An array is like a row of lockers: the array name identifies the row, the index identifies a position, and the value is what is stored there.
int[] scores = {82, 95, 71, 88};

This creates an integer array with four elements. The first element is at index 0, not index 1.

Key idea: array indexes start at zero. For an array with four elements, the valid indexes are 0, 1, 2, and 3.

Why use an array?

Without an array

You might create separate variables such as score1, score2, score3 and so on.

With an array

One variable stores all scores, and a loop can process them systematically.

2. Create an array and store values

Java arrays have a fixed length. You choose the length when creating the array, then read or replace values at its indexes.

Three common ways to create arrays

// 1. Declare and create an array with space for 5 integers int[] marks = new int[5]; // 2. Create and initialise in one step int[] ages = {12, 13, 14}; // 3. Replace the value at index 1 ages[1] = 15;

When Java creates a new int array, its elements start at 0. New boolean elements start at false, and object reference elements such as String start at null.

Array length is fixed. You can replace an element, but you cannot make a normal Java array longer after it is created. For a resizable collection, Java has ArrayList, which is a later topic.

3. Indexes, length and boundaries

An index is the position used to access one element. The length property tells you how many elements the array contains.

int[] numbers = {10, 20, 30}; System.out.println(numbers[0]); // 10 System.out.println(numbers.length); // 3 System.out.println(numbers[numbers.length - 1]); // 30
Important difference: length is the number of elements. The last index is length - 1.

Explore a boundary

This array has length 4, so indexes 0 through 3 are valid.

What is an ArrayIndexOutOfBoundsException?

Trying to access an index that does not exist causes an error. For an array of length 4, index 4 is invalid because the valid indexes are 0 to 3.

Common mistake: writing i <= array.length in a loop. The usual safe condition is i < array.length.

4. Traversal: visit every element

Traversal means visiting elements one by one. A loop is ideal because it can repeat the same operation for each index.

Classic for loop

int[] scores = {82, 95, 71}; for (int i = 0; i < scores.length; i++) { System.out.println(scores[i]); }

Read the loop header as: start i at 0; keep going while i is less than the array length; increase i by one after each pass.

Step through the loop

Press Next step to start the traversal.

Enhanced for loop

for (int score : scores) { System.out.println(score); }

The enhanced for loop gives you each value directly. Use it when you need to read each element and do not need its index.

Use classic for

When you need the index, want to update an element, or need to move by a particular step.

Use enhanced for

When you simply want to process every value in order.

5. Search an array

Searching means checking whether a value exists and, often, finding its index. Linear search checks elements from left to right until it finds the target or reaches the end.

int target = 71; int foundIndex = -1; for (int i = 0; i < scores.length; i++) { if (scores[i] == target) { foundIndex = i; break; } } System.out.println(foundIndex);

The value -1 is used here as a signal meaning “not found”. It is not a valid index in the array.

Run a linear search

Enter a target and start searching.
Linear search complexity: in the worst case it checks every element, so the work grows in proportion to the array length. This is commonly described as O(n). It works whether or not the array is sorted.
