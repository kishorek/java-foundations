1. Searching for text

Before using complicated patterns, learn the simple tools that answer common questions about a String.

Analogy: searching a book.
If you want to know whether a book contains the word “dragon”, you do not need to understand every sentence. You just need to search for that word. Java has simple methods for this kind of check.
contains()

Checks whether a String contains a specific sequence of characters.

String title = "Java for Beginners"; System.out.println(title.contains("Java")); // true System.out.println(title.contains("Python")); // false
startsWith() and endsWith()

Check the beginning or ending of a String.

"report.csv".startsWith("report"); // true "report.csv".endsWith(".csv"); // true
Case matters. contains("java") does not match "Java" because the uppercase J is different from lowercase j.

2. Find the position with indexOf()

Sometimes knowing that a word exists is not enough. You also need to know where it appears.

String sentence = "Java is fun. Java is useful."; System.out.println(sentence.indexOf("Java")); // 0 System.out.println(sentence.indexOf("fun")); // 8 System.out.println(sentence.indexOf("Python")); // -1 System.out.println(sentence.lastIndexOf("Java")); // 13
Analogy: a seat number. contains() answers “Is the person in the theatre?” indexOf() answers “Which seat are they in?”
  • indexOf(text) returns the first matching index.
  • lastIndexOf(text) returns the last matching index.
  • If no match exists, both return -1.
Index positions start at zero. A result of 0 means the match starts at the very beginning, not that it was not found.

3. What is pattern matching?

Sometimes the text you want to find is not one exact word. You want to recognise a shape or rule that many different strings can follow.

Analogy: a form at a reception desk.
A receptionist may accept any five-digit room number, not just one specific number. A pattern describes the rule that accepted values must follow.
Exact text search

Find the exact word "cat".

Matches: "cat"

Does not match: "cats" if searching with a whole-string exact comparison.

Pattern search

Find any three digits in a row.

Matches: "Room 204", "A123B"

Pattern: \\d{3} in Java regex.

Why regex?

Regular expressions, usually called regex, are compact patterns used to find, validate, or replace text. They are useful for phone-like digit sequences, postal codes, identifiers, repeated spaces, and data cleanup.

Beginner rule: use contains(), startsWith(), and endsWith() for simple questions. Reach for regex when you need a pattern rather than one literal sequence.

A regex is like a tiny language. Start with a few building blocks, then combine them to describe patterns.

How many?

QuantifierMeaningExample
*Zero or moreab* matches a, ab, abbb
+One or more\\d+ matches 8, 204
?Zero or onecolou?r matches color or colour
{3}Exactly three\\d{3} matches 204
{2,4}Between two and four\\d{2,4} matches 2 to 4 digits

Start, end, and groups

^ABC // starts with ABC XYZ$ // ends with XYZ ^\\d{5}$ // exactly five digits (ha)+ // one or more repetitions of "ha" (cat|dog) // either "cat" or "dog"
Very important: ^ means the start of the input and $ means the end. So ^\\d{5}$ means the entire input must contain exactly five digits. Without the anchors, a five-digit sequence could appear inside a longer string.
Java escaping: in a Java String literal, write "\\d+" to pass the regex \\d+. The first backslash escapes the second for Java's String syntax. Regex examples in this lesson show both the pattern and the Java form where needed.

5. Java regex methods

Java provides several ways to use regex. Choose the method based on the question you want to answer.

matches(): does the whole String fit?

String pin = "48291"; System.out.println(pin.matches("\\\\d{5}")); // true System.out.println("4829".matches("\\\\d{5}")); // false System.out.println("A8291".matches("\\\\d{5}")); // false

In Java, String.matches(regex) checks whether the entire String matches the pattern. It is not just a search for a matching part.

Pattern and Matcher: find a match inside text

import java.util.regex.Pattern; import java.util.regex.Matcher; String message = "Order numbers: 104 and 208"; Pattern pattern = Pattern.compile("\\\\d+"); Matcher matcher = pattern.matcher(message); while (matcher.find()) { System.out.println(matcher.group()); } // 104 // 208

find() looks for the next matching part. group() returns the matched text.

replaceAll(): replace matching patterns

String messy = "Java is fun"; String neat = messy.replaceAll("\\\\s+", " "); System.out.println(neat); // Java is fun

The regex \\s+ means one or more whitespace characters. This replaces each run of whitespace with one space.

Quick method chooser

Need to…Use

Validation note: regex can check format, not whether information is true or belongs to a real person. For example, a phone-like pattern cannot prove that a number is active. Real-world validation often needs additional checks.

Problem 1 · Find a word

Problem 2 · Find a position

Find the first occurrence of "cat" in "catapult and cat".

Problem 3 · Validate a five-digit PIN

Use matches() to accept exactly five digits, such as "48291", and reject "4829A".

String pin = "48291"; System.out.println(pin.matches("\\\\d{5}")); // true

For a Java String literal, use two backslashes before d.

Problem 4 · Find numbers in a sentence

Find all digit sequences in "Room 12, floor 4, block 105".

Pattern p = Pattern.compile("\\\\d+"); Matcher m = p.matcher("Room 12, floor 4, block 105"); while (m.find()) { System.out.println(m.group()); } // 12, then 4, then 105
Problem 5 · Collapse repeated spaces

Turn "Java is fun" into "Java is fun".

String text = "Java is fun"; System.out.println(text.replaceAll("\\\\s+", " "));
Problem 6 · Validate a simple username

Write a regex for a username that contains 3 to 10 English letters or digits only.

String username = "Kishore7"; boolean valid = username.matches("[A-Za-z0-9]{3,10}");

This is a simple teaching example. Real username rules may also allow underscores or other characters.

Problem 7 · Match a file extension

Check whether "data.csv" ends in .csv using a simple method, then think about when regex might help.

System.out.println("data.csv".endsWith(".csv")); // true

For this simple case, endsWith() is clearer than regex.

Problem 8 · Find either word

Find occurrences of either cat or dog in a sentence.

Pattern p = Pattern.compile("cat|dog"); Matcher m = p.matcher("A cat saw a dog"); while (m.find()) { System.out.println(m.group()); }

The pipe | means “OR” in regex.

Key takeaways

  • Use simple String methods for simple searches.
  • indexOf() returns an index or -1 when absent.
  • Regex describes patterns rather than only one exact word.
  • matches() checks the entire String; Matcher.find() searches inside text.
  • In Java String literals, regex backslashes must be escaped, such as "\\d+".
