1. Input and output: the conversation

Input is information your program receives. Output is information your program gives back.

Input

A person types a name, age, or price. A file or another system can also provide data.

Information goes in
Output

The program prints a greeting, calculation result, or message.

Information comes out
Analogy: ordering at a restaurant
You tell the server your order (input). The kitchen processes it. Your meal and bill are returned (output). A program follows a similar pattern: receive data, process it, then show a result.

3. Read keyboard input using Scanner

Scanner is a Java class that can read input from a source such as the keyboard. For console input, the common source is System.in.

import java.util.Scanner; class Main { public static void main(String[] args) { Scanner input = new Scanner(System.in); System.out.println("What is your name?"); String name = input.nextLine(); System.out.println("Hello, " + name); } }
1
import java.util.Scanner;

Makes the Scanner class available by its short name in this source file.

2
Scanner input = new Scanner(System.in);

Creates a Scanner named input that reads from standard input, usually the keyboard.

3
input.nextLine()

Reads a full line of text until the user presses Enter.

Analogy: Scanner is like a person taking down what you say. System.in is the source of the words, and nextLine() collects one whole line.

5. Common Scanner issues

A common beginner surprise happens when nextInt() is followed by nextLine().

int age = input.nextInt(); input.nextLine(); // consume the leftover newline String fullName = input.nextLine();

nextInt() reads the number but typically leaves the Enter newline waiting in the input. The next nextLine() may consume that leftover newline and return an empty string. The extra call consumes it first.

Analogy: a ticket queue
nextInt() takes the number ticket but leaves the Enter keypress in the queue. The next line reader sees that leftover Enter. Consume it before reading the full line.

Visualise the input buffer

int age = input.nextInt(); String name = input.nextLine();
age receives 14. name may become an empty string.

Other common mistakes

Forgetting the import

Add import java.util.Scanner; before the class.

Using a number method for text

Use nextLine() for a full name such as “Anu Devi”.

Invalid numeric input

Check the user's input or handle exceptions if it may not be a number.

Not closing Scanner

For a short console program, you may see input.close() at the end. Be careful closing a Scanner around System.in if more code still needs keyboard input.
