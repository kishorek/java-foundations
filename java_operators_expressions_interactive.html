Lesson 1

Operators are the action buttons of Java

An operator tells Java what action to perform on one or more values.

🧑‍🍳

Imagine a kitchen recipe. Ingredients are values, and actions such as mixing, adding, or checking are operators. An expression is the whole mini recipe that produces a result. Java is the chef who follows the instructions very literally, so do not ask it to “add a little bit” without being precise.

Lesson 2

Arithmetic: Java can do the maths

These operators calculate numbers, just like a calculator, with one important detail about division.

+ Addition

Add values together.

8 + 3 = 11

- Subtraction

Find the difference.

8 - 3 = 5

* Multiplication

The asterisk means multiply.

8 * 3 = 24

/ Division

Divide one value by another.

8 / 2 = 4

% Remainder

Find what is left after whole number division.

8 % 3 = 2

++ and --

Increase or decrease a variable by one.

score++
🍕

The remainder operator is the leftover pizza test. If 8 slices are shared equally among 3 people, each person gets 2 slices and 2 slices remain. So 8 % 3 gives 2.

Lesson 3

Comparison: ask a question

Comparison operators compare two values and return a boolean result, either true or false.

int age = 18; boolean canVote = age >= 18;

The expression age >= 18 asks whether age is greater than or equal to 18. Because age is 18, the answer is true.

==

Is equal to.

5 == 5 → true

!=

Is not equal to.

5 != 3 → true

> and <

Greater than or less than.

3 < 5 → true

>= and <=

Greater or equal, less or equal.

5 <= 5 → true
🚪

Think of a ticket gate. It checks a condition such as “Is this person at least 18?” The answer is either yes or no. A comparison does not itself change the age; it only produces an answer.

Test the comparison gate

Question
18 >= 18
Boolean answer
true ✓
Do not confuse these: = assigns a value, while == compares two values. One equals sign says “store this”; two equals signs ask “are these equal?”
Lesson 4

Logic and assignment: combine and update

Logical operators combine conditions, while assignment operators update what a variable stores.

&& AND

Both conditions must be true.

true && false → false

|| OR

At least one condition must be true.

true || false → true

! NOT

Flips a boolean result.

!true → false

+=, -=, *=

Update a variable using its current value.

score += 5
🎟️

Imagine getting into a theme park. The rule might be “You have a ticket AND you meet the height requirement.” Both must be true. If the rule says “You have a VIP pass OR a regular ticket,” either one is enough.

Lesson 5

Expressions and the order of operations

An expression combines values and operators to produce one result. Java follows precedence rules, much like the familiar order of operations in maths.

🧱

Think of a queue at a snack counter. Some tasks happen before others. Multiplication and division are handled before addition and subtraction unless parentheses tell Java to do something first.

See precedence in action

int answer = 2 + 3 * 4;
1
Multiply first.
3 * 4 becomes 12.
2
Then add.
2 + 12 becomes 14.
3
Store the result.
The variable answer receives 14.

Experiment with parentheses

Strings can use the plus sign too

String greeting = "Hello, " + "Maya";

When one or both operands are text, + can join the text together. This is called string concatenation, and the result here is "Hello, Maya".

Watch the order: "Score: " + 5 + 2 produces "Score: 52", because the numbers are converted to text as the expression is evaluated from left to right. By contrast, "Score: " + (5 + 2) produces "Score: 7".
