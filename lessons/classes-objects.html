Step 1

One plan, many homes

Shared design, private mess.

🏘️

Housing colony. Blueprint Book defines title, borrow(). Your copy: borrowed. Mine: free. Same DESIGN, different STATE.

ProgramRead each line in order
class Book {
  String title;       // every book has one
  boolean borrowed;   // ...and a borrow flag
  void borrow() { borrowed = true; }
}
Book b1 = new Book();   // build house #1
b1.title = "Dune";
b1.borrow();            // b1: borrowed. b2 (below) unaffected
Book b2 = new Book();   // build house #2
b2.title = "Solaris";   // b2: still free
