Step 1

Victim, witnesses, alibis

Later errors are usually gossip.

🕵️

Detective kit. Victim = error line. Witnesses = prints showing values. Rule: investigate the FIRST error — #2–#20 are its echoes. And never guess fixes (“maybe THIS?”) — science, not horoscopes.

syntaxRed ink, zero building
typeWrong types, no run
runtimeBuilds, then crashes mid-run
logicRuns fine, answers WRONG (dangerous)
Step 2

Main.java:7 means GO

Traces give addresses, not riddles.

ProgramRead each line in order
public class Main {
  public static void main(String[] args) {
    int[] m = {80, 90};
    System.out.println(m[0]); // 80: fine
    // System.out.println(m[5]); // INDEX 5 on length 2: crash!
    int total = m[0] + m[1];
    System.out.println("total = " + total); // 170?
  }
}

Valid index prints; the killer stays commented; total passes its oracle.
