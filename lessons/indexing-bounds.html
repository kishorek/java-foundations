Step 1

Top floor = floors − 1

Floor 9 doesn’t exist — security escorts you.

🏨

Hotel floors 0–4. Five floors, top = 4. Knock on 9 → ArrayIndexOutOfBoundsException. Java NEVER forgives — and that strictness is the feature (other languages return garbage).

Doors 0–2
public class Main {
  public static void main(String[] args) {
    int[] a = {5, 6, 7};
    System.out.println("first = " + a[0]);
    System.out.println("last = " + a[a.length - 1]);
    System.out.println("doors = " + a.length);
    // System.out.println(a[3]); // door 3 missing: CRASH
  }
}
First = 0, last = length − 1. Uncomment the a[3] line yourself to meet the exception personally.
