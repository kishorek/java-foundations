Boolean Expressions

Yes/no questions that power every decision. True, false — never maybe.

⏱ 14 min🧠 No experience needed🧪 Interactive
Step 1

Age? Ticket? Banned?

Three checks, one verdict.

🧍

The bouncer’s checklist. age ≥ 18? AND on the list? NOT banned? Each is true/false; combined verdict lifts the rope. Booleans never bend — no “maybe”, ever.

Voting check
int age = 20;
boolean canVote = age >= 18;      // true
boolean vip = age >= 18 && age < 65; // true
boolean deny = !(age >= 18);         // false
Comparisons make booleans; && || ! combine them. Order: !, comparisons, &&, ||.
Step 2

The guard that skips

false && ANYTHING never touches the right side.

Why is (s != null && s.length() > 0) safe?

Predict, then reveal the skip.

If s is null, the left side is false — && STOPS, and length() never runs. No crash, by design.
Text trap: == on Strings compares houses, not words. Content needs .equals().
