Main.java — save EXACTLY so
public class Main {
  public static void main(String[] args) {
    System.out.println("My kitchen works!");
  }
}
// Then in the terminal:
// javac Main.java
// java Main
Then in terminal: javac Main.java builds Main.class; java Main runs it.
