switch: The Mail Sorter

One value, many labeled slots. Arrows kill fall-through.

⏱ 14 min🧠 No experience needed🧪 Interactive
Step 1

One code, one slot

Default catches unknowns.

📮

Pincode sorter. Glances at ONE code, slides the letter into exactly one slot. Old style without break? The letter slides into the NEXT slot too (fall-through chaos). Arrow form -> can’t fall through.

ProgramRead each line in order
public class Main {
  public static void main(String[] args) {
    int day = 3;
    String name = switch (day) {
      case 1 -> "Monday";
      case 2 -> "Tuesday";
      case 3 -> "Wednesday";
      default -> "Unknown day";
    };
    System.out.println(name);
    System.out.println("Day " + day + " done");
  }
}

day = 3 matches one arrow; the expression yields the string.
