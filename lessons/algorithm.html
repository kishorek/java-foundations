Algorithms: Recipes for Machines

Finite steps, clear order, definite end — plus the max-of-two algorithm.

⏱ 12 min🧠 No experience needed🧪 Interactive
Step 1

Clear steps plus a guaranteed end

Unambiguous, ordered, finite — miss one and it is not an algorithm.

🌅

Think of a morning routine. Alarm → brush → dress → eat. Same order daily, ends when you leave. Now remove anything opinion-based (“dress nicely”) — that is an algorithm.

Pseudocode first: write the steps in plain words BEFORE coding. Logic errors found in words cost seconds; in code they cost much more.
Step 2

Watch a real algorithm decide

Compare, pick, print — always ending.

ProgramRead each line in order
public class Main {
  public static void main(String[] args) {
    int a = 7;   // input
    int b = 4;   // input
    int max;     // will hold the answer
    if (a > b) {
      max = a;
    } else {
      max = b;
    }
    System.out.println(max); // output: 7
  }
}

Steps run in order: store, compare, pick, print. One branch runs, the other sleeps.
