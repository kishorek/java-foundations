Casting: Buckets & Mugs

Widening pours free; narrowing spills — sign (int) and own the chop.

⏱ 14 min🧠 No experience needed🧪 Interactive
Step 1

Mug→bucket free, bucket→mug spills

Casts chop; they never round.

🪣

Funnels. int → long always fits (automatic). double → int spills — sign (int) to accept it. And the spill is silent truncation: (int) 3.99 = 3, not 4.

ProgramRead each line in order
public class Main {
  public static void main(String[] args) {
    int a = 5, b = 2;
    System.out.println(a / b);    // 2: int division chops
    System.out.println(a / 2.0);  // 2.5: double lifts the math
    double d = 3.99;
    int n = (int) d;              // 3: chop, never round
    System.out.println(n);
    long rounded = Math.round(d); // 4: real rounding
    System.out.println(rounded);
  }
}

int/int stays int; one double lifts all; casts chop; Math.round rounds.
