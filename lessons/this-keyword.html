this: “This Object Here”

Untangles shadowed names; phones sibling constructors.

⏱ 10 min🧠 No experience needed🧪 Interactive
Step 1

Which title?!

Field vs parameter crowd.

🪪

“I” name tag. Two titles in scope? this.title = MY field. this(...) phones my sibling constructor. No object (static)? No “I” — compile error.

Shadow, fixed
class Book {
  String title;
  Book(String title) {
    this.title = title; // FIELD = parameter
  }
  void rename(String title) {
    this.title = title; // same trick in methods
  }
}
Book b = new Book("Dune");
b.rename("Dune 2"); // b.title is now "Dune 2"
title = title self-assigns the parameter (field stays null!). this.title = title routes to the field.
