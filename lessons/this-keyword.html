The this Keyword

Stage 5 Concept ⏱ 10 min 📖 Glossary

this means “this object here”. It untangles “which title?” when parameters shadow fields.

🔎 Motivating questionIn “my bag is in my room”, who is “my”?

Objectives

  • Use this.field
  • Explain why shadowing needs this
  • Chain with this(...)

Needs first: Constructors

1 Start with an analogy

Real life first, code second.

Name tag “I”. In a crowd of Titles, this.title = MY title. Also this(...) calls my other constructor (sibling birth).

⚠️ Where the analogy breaksWhere it breaks: “I” outside a person is nonsense. this outside an object method/constructor is an error.

2 The concept, plainly

One idea at a time, words before jargon.

this.title = title: field = parameter. Fixes shadowing.

this(...) first line calls another constructor. this.method() explicit self-call (rare).

Use when names collide; otherwise optional.

3 Watch it move: Name tag

Step at your pace. Text explains every move.

4 Live code demo

Small, correct Java 17 (LTS) code. Read, trace, copy.

Main.javaJava 17
class Book {
  String title;
  Book(String title) { this.title = title; }
  void rename(String title) { this.title = title; }
}
Book b = new Book("Dune");
b.rename("Dune 2");
System.out.println(b.title);
▶ Output Dune 2
  • this.title = field.
  • title alone = parameter.
  • Rename updates the field.
💡 Why this output?Parameter assigned into the object’s field via this.

6 Common mistakes (at least 3)

Wrong, why, fixed — learn from realistic slips.

❌ Mistake 1: title = title; (no this)Why: Self-assigns parameter — field stays null!
✅ Fix: this.title = title;
❌ Mistake 2: this in static mainWhy: No “this object” there.
✅ Fix: Create an object first.
❌ Mistake 3: this(...) not first lineWhy: Must lead.
✅ Fix: Put this(...) line 1.
