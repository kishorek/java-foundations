Generics: Luggage Tags

List of String refuses socks at PACKING. Tags wash off at runtime.

⏱ 14 min🧠 No experience needed🧪 Interactive
Step 1

Beep at drop-off

Not discovery at unpacking.

🧳

Labeled bins. String-bin beeps at socks DURING packing (compile error). Raw bin swallows all — ClassCastException at unpacking, far from the crime. Tags wash off after (erasure); primitives can’t ride (no List of int).

Tagged bin
import java.util.ArrayList;
import java.util.List;
List<String> names = new ArrayList<>(); // tagged bin
names.add("Ada");                       // accepted
// names.add(5); // COMPILE ERROR - the guard beeps
names.get(0).length(); // 3: no cast needed
Diamond <> copies the tag right. get() needs NO cast — the tag proves content.
