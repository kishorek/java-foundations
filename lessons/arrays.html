Arrays: Egg Trays

One type, numbered from 0, fixed at birth. Length never moves.

Step 1

12 slots, zero stretch

Need 13? New tray (or ArrayList later).

🥚

Egg tray. Fixed slots, slot 0 first. Never stretches, never mixes types. Unused slots hold defaults (0 / false / null) — not “empty”.

ProgramRead each line in order
public class Main {
  public static void main(String[] args) {
    int[] eggs = {10, 20, 30};
    System.out.println("slots = " + eggs.length);
    System.out.println("first = " + eggs[0]);
    eggs[1] = 99; // swap slot 1
    System.out.println("swapped = " + eggs[1]);
    System.out.println("last = " + eggs[eggs.length - 1]);
  }
}
