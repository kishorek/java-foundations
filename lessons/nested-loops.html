Nested Loops

Outer picks rows, inner visits seats. Total = rows × seats.

Step 1

Rows × seats, every show

Inner restarts per outer round.

🎬

Cinema usher. Walks rows 1–5 (outer); at EACH row counts seats 1–8 (inner, restarting). Total = 5 × 8 = 40 visits. 100×100 = 10,000 — nesting multiplies QUADRATICALLY.

public class Main {
  public static void main(String[] args) {
    for (int r = 1; r <= 2; r++) {
      for (int c = 1; c <= 3; c++) {
        System.out.print(r + "x" + c + " ");
      }
      System.out.println(); // end of row r
    }
    System.out.println("seats = 6");
  }
}
