Step 2
"Age: " + 18 + 2 = ?
Left-to-right gluing, revealed.

      
ProgramRead each line in order

      
public class Main {
  public static void main(String[] args) {
    String name = "Ada";
    int age = 18;
    String msg = "Hi " + name + ", age " + age;
    System.out.println(msg);
    System.out.println("length = " + msg.length());
    System.out.println(msg.equals("Hi Ada, age 18"));
  }
}
