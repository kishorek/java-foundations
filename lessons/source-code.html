What Is Source Code?

Stage 1 Concept ⏱ 10 min 📖 Glossary

Source code is the human-readable text you write. The computer later translates it — but humans must read it first, including future you.

🔎 Motivating questionWhy do chefs write recipes instead of just filming themselves once?

Objectives

  • Explain source code
  • Read a tiny code sample
  • Tell code from the running app

Needs first: What Is an Algorithm?

1 Start with an analogy

Real life first, code second.

A recipe book vs the meal. The book (source) can be shared, edited, and re-cooked. The meal (running app) disappears after eating.

⚠️ Where the analogy breaksWhere it breaks: you can still eat without the recipe. A computer cannot run without translated code — source alone does nothing until built.

2 The concept, plainly

One idea at a time, words before jargon.

Source code = plain-text instructions in a language like Java. Files end in .java.

Code has strict syntax (spelling/grammar). One missing semicolon can stop translation.

We write for two readers: the translator (strict) and humans (need clear names and layout).

3 Watch it move: Source → translator → app

Step at your pace. Text explains every move.

4 Live code demo

Small, correct Java 17 (LTS) code. Read, trace, copy.

Main.javaJava 17
// Hello.java — source code (human readable)
public class Hello {
  public static void main(String[] args) {
    System.out.println("Hi, future programmer!");
  }
}
▶ Output Hi, future programmer!
  • Line 1 is a comment — for humans only.
  • Lines 2-3 wrap the program in a class + starting point.
  • Line 4 is the real instruction.
💡 Why this output?The translator keeps line 4 as an instruction and ignores the comment. Running prints the text.

6 Common mistakes (at least 3)

Wrong, why, fixed — learn from realistic slips.

❌ Mistake 1: Editing the app instead of the code.Why: The running app is output; fixes go in source.
✅ Fix: Change .java, rebuild, run again.
❌ Mistake 2: Ignoring one red semicolon error.Why: Syntax is all-or-nothing for the translator.
✅ Fix: Read the first error line, fix, rebuild.
❌ Mistake 3: Names like a1, x2, tmp.Why: Works for the machine, painful for humans.
✅ Fix: Use total, userName, price.

7 Guided practice

Hints first, solutions only after a real try.
