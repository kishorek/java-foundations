Source Code: Text That Becomes Apps

Human-readable text, strict syntax, and the two readers of every file.

⏱ 10 min🧠 No experience needed🧪 Interactive
Step 1

The book, not the dinner

Source is potential; the running app is dinner.

📖

A recipe book versus the meal. The book can be shared, reviewed, corrected, re-cooked. The meal vanishes after eating. Fix the BOOK, never the meal.

Java example
// Hello.java — source code (human readable)
public class Hello {
  public static void main(String[] args) {
    System.out.println("Hi, future programmer!");
  }
}
Two readers: the translator (strict, dumb) and humans (need clear names). Professionals write for the humans.
