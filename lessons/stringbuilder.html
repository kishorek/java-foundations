Whiteboard. Append a line per visitor, erase typos in place, photograph (toString) at the end. append returns THIS — chains cost nothing.

ProgramRead each line in order
public class Main {
  public static void main(String[] args) {
    StringBuilder sb = new StringBuilder();
    for (int i = 1; i <= 3; i++) {
      sb.append(i).append(" ");
    }
    System.out.println("built = " + sb.toString());
    sb.reverse(); // edits the SAME board, in place!
    System.out.println("flipped = " + sb.toString());
  }
}

One object absorbs all appends; reverse flips the SAME board.
