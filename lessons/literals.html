Step 1

Twenty notes or one tag?

final PI = single truth, reused safely.

🏷️

Name tags vs sticky notes. 3.14159 scribbled 20× rots separately. final double PI = 3.14159 is one engraved tag — change once, correct everywhere. Reassigning it breaks the build ON PURPOSE.

The engraved tag
public class Main {
  public static void main(String[] args) {
    final double PI = 3.14159; // engraved tag
    int count = 1000;
    long big = 5000000000L;
    double circle = PI * 2 * 2; // 2πr with r = 2
    System.out.println("PI = " + PI);
    System.out.println("count = " + count);
    System.out.println("circle = " + circle);
  }
}
UPPER_CASE shouts “do not touch”. Integers born int (L for long), decimals born double (f for float).
