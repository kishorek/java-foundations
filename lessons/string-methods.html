String Toolkit

Seven tools for 90% of text work: measure, peek, slice, find, compare, clean, split.

⏱ 14 min🧠 No experience needed🧪 Interactive
Step 1

Ruler, tweezers, scissors…

One tool per text job.

🔪

Swiss knife. length() ruler, charAt() tweezers, substring() scissors, equals() scale, trim() towel, split() cutter. But scissors return FRESH paper — originals never cut!

📏

length()

Counts every character, spaces included.

Example: "Hi" → 2
🔍

charAt(i)

Peeks at slot i. Zero-based, crashes past end.

Example: "Hi".charAt(0)
✂️

substring(a,b)

Slices a..b with b EXCLUDED.

Example: "Java" → "Ja"
⚖️

equals()

Compares CONTENT, unlike ==.

Example: s.equals("x")
🧹

trim()

Shaves edge whitespace, returns new.

Example: " a ".trim()
🔎

indexOf(x)

Finds position; −1 means absent.

Example: "Java".indexOf("v")
