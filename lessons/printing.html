Printing Output

println vs print vs printf — plus the left-to-right glue trap.

⏱ 12 min🧠 No experience needed🧪 Interactive
Step 1

Three heads, three habits

Break line, stay put, fill blanks.

🖨️

A label printer. println prints + feeds a new line; print stays; printf fills blanks (“$__. __”). Plain text only — no colors without extra tools.

Java example
public class Main {
  public static void main(String[] args) {
    System.out.println("Apples: " + 3);
    System.out.print("Total: ");
    System.out.println(3 * 2);
    System.out.printf("Price: $%.2f%n", 2.5);
    System.out.printf("%s is %d years old%n", "Ada", 18);
  }
}
Watch line 2–3: print leaves the cursor waiting, so println(6) lands on the SAME line: “Total: 6”.

Step 3

printf placeholders

%d, %.2f, %s, %n — and rounding.

ProgramRead each line in order
System.out.printf("Price: $%.2f%n", 2.5);
System.out.printf("%s is %d%n", "Ada", 18);

Placeholders fill in order; %.2f rounds to two places.

Rounded
%s, %d

In order
%.2f rounds (2.555 → 2.56). %n is the portable newline.
