Name it once, cook it anywhere. Fix once, improve everywhere.

Step 1

Press B3, snack drops

Reuse without knowing insides.

🥤

Vending machine. Press B3 (call), hidden steps run, snack drops. Reuse forever without caring about insides. Copy-paste instead? The bug gets fixed twice and survives in copy three.

Chef.java
public class Chef {
  static void greet() {
    System.out.println("Welcome!");
  }

  public static void main(String[] args) {
    greet();
    greet();
    System.out.println("Seated: 2 guests");
  }
}
Define once, call often. Each call jumps in, runs, jumps back. void = does things, returns nothing.
