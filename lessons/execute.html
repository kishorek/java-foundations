How Computers Execute Programs

Fetch, decode, execute — billions of tiny steps with memory as the workbench.

⏱ 14 min🧠 No experience needed🧪 Interactive
Step 1

Shelf, counter, hands

Disk stores, RAM stages, CPU acts — one card at a time.

👨‍🍳

Think of a kitchen. Recipe shelf (disk) → counter (RAM) → chef hands (CPU). Ingredients travel shelf → counter → hands, one card at a time, billions of times per second.

Where it breaks: chefs improvise. A CPU does exactly one tiny operation per tick with zero improvisation — speed comes from tick COUNT, not cleverness.
Step 2

Load, load, add, print

Four trivial steps become “add and print”.

ProgramRead each line in order
public class Main {
  public static void main(String[] args) {
    int a = 4;              // LOAD 4 into memory slot a
    int b = 5;              // LOAD 5 into memory slot b
    int c = a + b;          // ADD the slots into c
    System.out.println(c);  // PRINT c  -> shows 9
  }
}

Each line is fetch → decode → execute. Comments map the machine steps.
