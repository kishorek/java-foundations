Primitive Data Types

Stage 2 Concept ⏱ 20 min 📖 Glossary

Java has exactly 8 built-in value types. Pick the smallest box that safely fits — usually int, double, boolean, char.

🔎 Motivating questionWhy sell milk in 250ml, 500ml, and 1L — not just one giant tanker?

Objectives

  • Name the 8 primitives
  • Pick int vs double vs boolean
  • Explain ranges simply

Needs first: Variables: Your Program's Storage Boxes

1 Start with an analogy

Real life first, code second.

Measuring cups. byte (tiny espresso), int (mug), long (bucket), float/double (graduated cylinders), char (single letter tile), boolean (light switch).

⚠️ Where the analogy breaksWhere it breaks: cups spill visibly. Numeric overflow wraps silently (127 + 1 → -128 in byte). Choose big enough!

2 The concept, plainly

One idea at a time, words before jargon.

Integers: byte ±128, short ±32k, int ±2 billion (default), long huge (add L).

Decimals: float ~7 digits (add f), double ~15 digits (default for 3.5). Use double unless told otherwise.

char one UTF-16 unit (like a), boolean true/false. char is a number underneath (A = 65).

3 Watch it move: Sizing boxes

Step at your pace. Text explains every move.

4 Live code demo

Small, correct Java 17 (LTS) code. Read, trace, copy.

Main.javaJava 17
int people = 30;
long worldPop = 8_000_000_000L;
double price = 19.99;
float temp = 36.6f;
char grade = 'A';
boolean passed = true;
System.out.println(people + " " + price + " " + grade);
▶ Output 30 19.99 A
  • L marks long; f marks float.
  • 3.5 alone is double.
  • char uses single quotes.
💡 Why this output?Each literal fits its type; + with strings joins for display.

6 Common mistakes (at least 3)

Wrong, why, fixed — learn from realistic slips.

❌ Mistake 1: long x = 8000000000; (no L)Why: Bare number is int — too big!
✅ Fix: long x = 8_000_000_000L;
❌ Mistake 2: float t = 36.6; (no f)Why: 36.6 is double; cannot squeeze silently.
✅ Fix: float t = 36.6f; or use double.
❌ Mistake 3: char c = "a";Why: Double quotes = String, not char.
✅ Fix: char c = 'a';
