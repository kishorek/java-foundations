Step 1

Espresso to bucket

Pick the smallest box that safely fits.

🥛

Measuring cups. byte = espresso shot, int = everyday mug, long = bucket, float/double = graduated cylinders, char = letter tile, boolean = light switch. Overflow? Cups spill LOUDLY. Numbers wrap SILENTLY (127 + 1 → −128).

🫘

byte

Tiny whole numbers −128 to 127. Storage, not math.

Example: 100
📏

short

Small whole numbers ±32k. Bigger than byte.

Example: 25000
🔢

int

Whole numbers ±2.1 billion. The default choice.

Example: 18
🏦

long

Huge whole numbers. Big literals need L.

Example: 8000000000L
🪙

float

~7 trustworthy digits. Decimals need f.

Example: 36.6f
💧

double

~15 digits. Default for 3.5. Money + science.

Example: 19.99
🔠

char

One UTF-16 unit in single quotes. Secretly a number.

Example: 'A' (=65)
✅

boolean

Exactly true or false. No 0/1 tricks.

Example: true

L, f, and quotes

Your Java statement


Classic fails: long x = 8000000000; (literal overflows as int first!) and float t = 36.6; (born double). Suffix the LITERAL: 8000000000L, 36.6f.
