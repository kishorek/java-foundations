Primitive Data Types

Stage 2 Concept ⏱ 20 min 📖 Glossary

Java ships exactly 8 built-in value types — no more, no less. Pick the smallest box that safely fits your data; in practice that means int, double, boolean, and char carry 95% of beginner code.

🔎 Motivating questionWhy do shops sell milk in 250 ml, 500 ml, and 1 L instead of one giant tanker per customer?

Objectives

  • Name the 8 primitives
  • Pick int vs double vs boolean
  • Explain ranges simply

Needs first: Variables: Your Program's Storage Boxes

1 Start with an analogy

Real life first, code second.

Measuring cups. byte is the espresso shot, int the everyday mug, long the bucket; float and double are graduated cylinders of different precision; char is a single letter tile; boolean is a light switch.

⚠️ Where the analogy breaksWhere it breaks: cups spill visibly and loudly. Numeric overflow wraps SILENTLY — byte 127 + 1 becomes -128 with no warning. Undersized boxes corrupt data instead of complaining.

2 The concept, plainly

One idea at a time, words before jargon.

Integers: byte (±128), short (±32 thousand), int (±2.1 billion, the default), long (about ±9.2 × 10¹⁸, needs an L suffix). Bigger box, bigger range, more memory.

Decimals: float (~7 trustworthy digits, needs an f suffix) vs double (~15–16 digits, the default for 3.5). Money and science want double; float is for special cases like graphics.

char holds one UTF-16 code unit in single quotes — (int) ’A’ is 65 underneath. boolean is exactly true or false, nothing else, no 0/1 tricks like C.

Naked numbers have default types: 5 is int, 3.5 is double, true is boolean. Suffixes override: 5L is long, 3.5f is float, ’a’ is char.

⚙️ Tech details — precise facts
  • Exact ranges: byte −128..127, short −32,768..32,767, int −2,147,483,648..2,147,483,647, long ≈ ±9.2×10¹⁸, char 0..65,535.
  • long big = 8000000000; FAILS — the literal is int-sized first, so it overflows before assignment. Always write 8000000000L.
  • float t = 36.6; FAILS — 36.6 is double and Java never silently squeezes it. Write 36.6f or use double.
  • A char is secretly a number: ’A’+1 is ’B’, and (int)’A’ is 65. Emoji mostly need TWO chars (surrogate pairs) — char is a UTF-16 unit, not “one symbol”.

4 Live code demo

Small, correct Java 17 (LTS) code. Read, trace, copy.

Main.javaJava 17
public class Main {
  public static void main(String[] args) {
    int people = 30;
    long worldPop = 8000000000L;
    double price = 19.99;
    float temp = 36.6f;
    char grade = 'A';
    boolean passed = true;
    System.out.println(people);
    System.out.println(worldPop);
    System.out.println(price + " " + temp + " " + grade + " " + passed);
  }
}
▶ Output 30 8000000000 19.99 36.6 A true
  • The L marks a long literal; the f marks a float literal.
  • Bare 3.5-style decimals are always double.
  • char uses single quotes; boolean prints as true/false.
▶️ Run it yourselfSave exactly as Main.java, then javac Main.java and java Main. Every full program in this course works this way.

6 Common mistakes (at least 3)

Wrong, why, fixed — learn from realistic slips.

❌ Mistake 1: long x = 8000000000; with no L.Why: The bare literal is int — it overflows BEFORE the assignment happens.
✅ Fix: long x = 8000000000L; — suffix the literal itself.
❌ Mistake 2: float t = 36.6; with no f.Why: 36.6 is born double; Java will not squeeze it silently.
✅ Fix: float t = 36.6f; — or simply use double.
❌ Mistake 3: char c = "a"; with double quotes.Why: Double quotes build a String object, never a char.
✅ Fix: char c = ’a’; — singles for tiles, doubles for strings.
❌ Mistake 4: byte b = 100; b = b + 1; expecting 101 in a byte.Why: byte math promotes to int — and 127 + 1 wraps to -128 anyway.
✅ Fix: Use int for math; treat byte/short as storage types.

9 Takeaways + next step

  • 8 primitives; bare integers default to int, decimals to double.
  • L marks long, f marks float, single quotes mark char.
  • Overflow wraps silently — size the box before the math.
  • char is a UTF-16 number; boolean is strictly true/false.
