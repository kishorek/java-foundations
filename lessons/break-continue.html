Emergency exit vs skipping one dance move. Reshape loops without nesting.

Step 1

Skip square 4, or go home?

Skipping ≠ quitting.

🤸

Hopscotch. continue = hop OVER square 4, keep playing. break = stop the game, go home. Reserve break for “FOUND IT!” and continue for “skip bad data”.

ProgramRead each line in order
public class Main {
  public static void main(String[] args) {
    for (int i = 1; i <= 5; i++) {
      if (i == 3) {
        continue; // skip printing 3, keep looping
      }
      if (i == 5) {
        break; // stop the whole loop before 5
      }
      System.out.println(i);
    }
    System.out.println("over");
  }
}

Round 3’s print jumped; round 5 ends everything.
