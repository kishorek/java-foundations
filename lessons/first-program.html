Your First Java Program

Stage 2 Concept ⏱ 15 min 📖 Glossary

Every Java program wears the same uniform: a class shell and a main door. Learn the uniform once and you will recognize — and write — every program in this course.

🔎 Motivating questionWhy do all formal letters start with “Dear…” and end with a signature?

Objectives

  • Explain class + main
  • Write Hello World
  • Run it and read output

Needs first: Setting Up Java and Running a Program

1 Start with an analogy

Real life first, code second.

Envelope plus letter. The class is the envelope with your name on it (Main). main is the big arrow saying “start reading HERE”. The JVM always opens the envelope exactly at main.

⚠️ Where the analogy breaksWhere it breaks: you can start reading a letter anywhere. The JVM cannot — it demands precisely main(String[] args). Close cousins like Main or main() with no args are rejected.

2 The concept, plainly

One idea at a time, words before jargon.

public class Main names the blueprint; the file must be Main.java. Everything the program owns lives inside its braces.

public static void main(String[] args) is the start door. Each word has a technical meaning you will earn over the course — for now, memorize its exact shape.

Statements end with ; and braces { } group code into blocks. System.out.println prints text plus a newline. The JVM runs main top-down, line by line.

Later you will learn what public, static, void, and String[] args each mean (methods, scope, arrays). For now they are the magic words that open the door — spelled exactly.

⚙️ Tech details — precise facts
  • public = visible to the JVM launcher. static = runnable without building an object first. void = returns nothing. String[] args = command-line words handed to your program.
  • The entry signature must match exactly: public static void main(String[] args). Even Main (capital M) fails the search.
  • One file can hold many classes, but at most one public class — and the file is named after it.

3 Watch it move: Entering main

Step at your pace. Text explains every move.

4 Live code demo

Small, correct Java 17 (LTS) code. Read, trace, copy.

Main.javaJava 17
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello, Java!");
    System.out.println("I am learning.");
    System.out.println("Line by line.");
  }
}
▶ Output Hello, Java! I am learning. Line by line.
  • Line 1: the envelope, named Main.
  • Line 2: the start-here door, exact shape.
  • Lines 3–5: three instructions, each ending with a semicolon, running top-down.
▶️ Run it yourselfSave exactly as Main.java, then javac Main.java and java Main. Every full program in this course works this way.
💡 Why this output?The JVM entered main, ran line 3 (print), then 4, then 5, then exited. Order is strictly top-down — no skipping, no guessing.

6 Common mistakes (at least 3)

Wrong, why, fixed — learn from realistic slips.

❌ Mistake 1: main spelled Main, or String[] args missing.Why: The JVM searches for one exact signature and accepts no substitutes.
✅ Fix: Copy precisely: public static void main(String[] args).
❌ Mistake 2: A forgotten semicolon at a line end.Why: Without it Java cannot tell where the instruction ends.
✅ Fix: End every statement with a semicolon.
❌ Mistake 3: File Main.java but class main (lowercase).Why: Case mismatch: the envelope name does not match the file.
✅ Fix: Match exactly: Main inside Main.java.
