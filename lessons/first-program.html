Your First Java Program

The class envelope, the main door, and three lines that obey.

⏱ 15 min🧠 No experience needed🧪 Interactive
Step 1

Learn the uniform once

Every Java program wears it.

✉️

Envelope plus letter. Class = envelope named Main. main = the arrow saying START HERE. The JVM opens every envelope exactly at main — no substitutes.

Main.java
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello, Java!");
    System.out.println("I am learning.");
    System.out.println("Line by line.");
  }
}
Read it: envelope (class) → door (main) → three instructions, each ending with ;, running top-down.
