Museum audit. Rooms (packages), exhibits (objects), rules (encapsulation), wings (inheritance), passes (interfaces), installs (composition). Then BUILD — audits admire, builders build.

OOP minimum
class MiniBook {
  private String title;              // vault
  MiniBook(String t) { title = t; }  // birth
  String getTitle() { return title; } // window
}
MiniBook b = new MiniBook("Dune");
// b.getTitle() gives "Dune"
Private + constructor + getter = smallest honest object. Next: borrowed flag, then Library of many.
