Step 1

Carts here, payments there

Full addresses end Apple wars.

🏪

Supermarket aisles. com.shop.cart vs com.shop.pay. Two “Apples” (fruit vs tech)? Full aisle addresses disambiguate. Folders MUST mirror dots — or nothing resolves.

Cart shelf
package com.shop; // shelf label: FOLDERS must mirror this

import java.util.ArrayList; // borrow the tool
import java.util.List;

public class Cart {
  private List<String> items = new ArrayList<>();
  void add(String s) { items.add(s); }
  int size() { return items.size(); }
}
package DECLARES; import BORROWS. java.lang (String, Math) is free air. Stars borrow ONE shelf, never sub-shelves.
