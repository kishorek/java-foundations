Packages and Imports

Stage 5 Concept ⏱ 12 min 📖 Glossary

Packages are labeled shelves: com.shop.cart holds Cart classes. Imports borrow from other shelves without name fights.

🔎 Motivating questionWhy do libraries shelve fiction apart from science?

Objectives

  • Organize with packages
  • Import classes
  • Avoid name clashes

Needs first: Composition

1 Start with an analogy

Real life first, code second.

Supermarket aisles: com.shop.cart (carts), com.shop.pay (payments). Two Apples (fruit vs tech)? Aisles disambiguate: fruit.Apple vs tech.Apple.

⚠️ Where the analogy breaksWhere it breaks: aisles do not lock. Packages organize + gate (package-private); jars still need discipline.

2 The concept, plainly

One idea at a time, words before jargon.

package com.shop; first line. Folders mirror dots. import java.util.List; borrows.

java.lang auto-imported (String, Math). * imports a shelf (not sub-shelves).

Clash? Use full name: java.util.Date vs java.sql.Date.

6 Common mistakes (at least 3)

Wrong, why, fixed — learn from realistic slips.

❌ Mistake 1: No package, 50 files flatWhy: Name soup.
✅ Fix: Group by feature.
❌ Mistake 2: import java.util.*; expecting subpackagesWhy: * is shallow.
✅ Fix: Import each shelf.
❌ Mistake 3: Two Dates clashWhy: Ambiguous.
✅ Fix: Full name one of them.
