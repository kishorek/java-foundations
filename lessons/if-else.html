if / else if / else

One question, two futures. First true branch wins; the rest sleep.

⏱ 16 min🧠 No experience needed🧪 Interactive
Step 1

Raining? Left. Else right.

Exactly one path walks.

🥾

A fork on a trek path. Sign says raining? Left to shelter, else right to viewpoint. You walk ONE branch, never both — and code can’t turn back.

ProgramRead each line in order
public class Main {
  public static void main(String[] args) {
    int marks = 82;
    if (marks >= 90) {
      System.out.println("Grade A");
    } else if (marks >= 75) {
      System.out.println("Grade B");
    } else if (marks >= 60) {
      System.out.println("Grade C");
    } else {
      System.out.println("Keep going");
    }
  }
}

82 fails ≥90, passes ≥75. Later branches never evaluate.
