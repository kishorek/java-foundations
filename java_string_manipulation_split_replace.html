1. What is a String?

A String is a sequence of characters used to represent text, such as a name, address, product code, or sentence.

Analogy: a necklace of letters.
Each character is like a bead in a row. Java counts positions from zero, so the first character is at index 0, the second at 1, and so on.
String name = "Nituna"; System.out.println(name.length()); // 6 System.out.println(name.charAt(0)); // N System.out.println(name.charAt(5)); // a
Character indexes
N 0i 1t 2u 3n 4a 5
Length vs last index

Length is 6, but the last index is 5.

lastIndex = length - 1
Important: Strings are immutable. Methods such as toUpperCase() return a new String. They do not modify the original value automatically.
String city = "chennai"; city.toUpperCase(); System.out.println(city); // chennai city = city.toUpperCase(); System.out.println(city); // CHENNAI

2. Essential String methods

These methods are the everyday toolkit for inspecting and comparing text.

Comparing Strings: Use equals() for text content. The == operator checks whether two references point to the same object, not whether their text is equal.
String first = "Java"; String second = new String("Java"); System.out.println(first == second); // false in this example System.out.println(first.equals(second)); // true
Tip: trim() removes leading and trailing basic spaces, not spaces in the middle. For example, "New Chennai".trim() remains "New Chennai".

3. Extract text with substring()

Use substring() when you need only part of a String.

String word = "PROGRAM"; System.out.println(word.substring(2)); // OGRAM System.out.println(word.substring(1, 4)); // ROG
Analogy: seats in a row. In substring(1, 4), indexes 1, 2 and 3 are included. Index 4 is the stopping boundary and is not included.

Valid indexes must fit the String. For the two-argument version, the start must be less than or equal to the end, and the end cannot exceed the String length.

4. Replace text with replace()

replace() returns a new String with matching characters or literal text replaced. It is case-sensitive.

String message = "I like tea"; String updated = message.replace("tea", "coffee"); System.out.println(updated); // I like coffee System.out.println(message); // I like tea

Use single quotes for character replacement, such as replace('a', 'o'), or double quotes for literal text, such as replace("cat", "dog").

Do not confuse these: replace() treats the search value as literal text. replaceAll() treats its first argument as a regular expression. Regex is covered in the next Strings lesson.

5. Split text with split()

split() divides a String into a String array using a delimiter, such as a comma, space, or hyphen.

String csv = "Ravi,Anu,Kumar"; String[] names = csv.split(","); System.out.println(names[0]); // Ravi System.out.println(names[1]); // Anu System.out.println(names.length); // 3
Analogy: cutting a dosa into pieces. The delimiter marks where to cut the text into separate pieces.
InputJava expressionPieces
"red,blue,green"split(",")red · blue · green
"one two three"split(" ")one · two · three
"2026-10-10"split("-")2026 · 10 · 10
"a|b|c"split("\\|")a · b · c
Important: split() accepts a regular expression as its delimiter. A dot has a special meaning in regex, so split on a literal dot using split("\\."), not split("."). Java source code needs the doubled backslash.

7. Practice problems

Try each problem before revealing the sample solution. Focus on understanding why the code works.

Problem 1 · Count characters

Print the number of characters in "Chennai".

System.out.println("Chennai".length()); // 7
Problem 2 · First and last character

Print the first and last character of "Java".

String word = "Java"; System.out.println(word.charAt(0)); // J System.out.println(word.charAt(word.length() - 1)); // a
Problem 3 · Compare ignoring case

Check whether "JAVA" and "java" are equal ignoring case.

System.out.println("JAVA".equalsIgnoreCase("java")); // true
Problem 4 · Extract a file extension

From "report.csv", extract "csv".

String file = "report.csv"; int dot = file.lastIndexOf('.'); String extension = file.substring(dot + 1); System.out.println(extension); // csv
Problem 5 · Replace a word

Change every occurrence of "bad" to "good" in a sentence.

String text = "bad weather, bad traffic"; System.out.println(text.replace("bad", "good"));
Problem 6 · Split CSV text

Split "Kishore,Chennai,Java" and print each part on a new line.

String[] parts = "Kishore,Chennai,Java".split(","); for (String part : parts) { System.out.println(part); }
Problem 7 · Clean user input

Remove leading and trailing spaces from " hello ", then convert it to uppercase.

String input = " hello "; String cleaned = input.trim().toUpperCase(); System.out.println(cleaned); // HELLO
Problem 8 · Count words

Count the words in "Java is fun".

String sentence = "Java is fun"; String[] words = sentence.split(" "); System.out.println(words.length); // 3

For input with repeated or irregular whitespace, clean and split using whitespace handling covered in the regex lesson.

Key takeaways

  • String indexes start at zero.
  • Strings are immutable, so methods return new values.
  • Use equals() to compare text content.
  • substring() extracts a portion of text.
  • replace() changes matching literal text in the returned String.
  • split() creates an array and uses a regex delimiter.
