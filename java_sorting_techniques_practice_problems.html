1. Why do we sort?

Sorting means arranging values into a chosen order, such as smallest to largest or A to Z.

Analogy: line up a class by height.
You compare people, decide who should come first, and keep arranging the line until it is in order. A sorting algorithm follows a precise set of steps to do something similar with data.

Where sorting helps

Ranking marks, showing products by price, arranging names alphabetically, preparing data for reports, and making some search tasks easier.

Learning goal: First understand the logic behind bubble sort and selection sort. Then learn the standard Java methods you would normally use in real applications.

2. Bubble sort

Bubble sort compares neighbouring values. If they are in the wrong order, it swaps them. After each pass, the largest unsorted value moves to the end.

Analogy: big bubbles moving to the surface.
Large values gradually move toward the right as adjacent pairs are compared.
for (int i = 0; i < numbers.length - 1; i++) { for (int j = 0; j < numbers.length - 1 - i; j++) { if (numbers[j] > numbers[j + 1]) { int temp = numbers[j]; numbers[j] = numbers[j + 1]; numbers[j + 1] = temp; } } }

Understand the swap

The temporary variable acts like a spare cup. It safely holds one value while the other value is moved.

int temp = a; a = b; b = temp;

3. Selection sort

Selection sort finds the smallest value in the unsorted part, then swaps it into the next correct position.

Analogy: choose the shortest person first.
Find the shortest person in the whole line and put them first. Then find the shortest among the remaining people and put them second.
for (int i = 0; i < numbers.length - 1; i++) { int minIndex = i; for (int j = i + 1; j < numbers.length; j++) { if (numbers[j] < numbers[minIndex]) { minIndex = j; } } int temp = numbers[i]; numbers[i] = numbers[minIndex]; numbers[minIndex] = temp; }

minIndex stores the index of the smallest value found so far. Once the scan finishes, that value is swapped into position i.

Notice the difference: bubble sort swaps adjacent values many times. Selection sort scans for the minimum and usually makes at most one swap per pass.

4. Built-in Java sorting

In everyday Java programs, prefer the standard library instead of writing a basic sorting algorithm yourself.

Sort an array

import java.util.Arrays; int[] marks = {72, 45, 90, 61}; Arrays.sort(marks); System.out.println(Arrays.toString(marks)); // [45, 61, 72, 90]

Sort a list

import java.util.ArrayList; import java.util.Collections; ArrayList<Integer> prices = new ArrayList<>(); prices.add(500); prices.add(120); prices.add(300); Collections.sort(prices); System.out.println(prices); // [120, 300, 500]

Sort a list in descending order

Collections.sort(prices, Collections.reverseOrder()); // [500, 300, 120]
Remember: Arrays.sort(array) changes the order in the original array. Sorting a list also changes the order of that list.

5. Compare the approaches

Algorithms are different ways to solve the same problem. Their performance matters as the amount of data grows.

ApproachCore ideaTypical timeUse it for
Bubble sortCompare adjacent pairs and swapO(n²)Learning comparisons and swaps
Selection sortFind the minimum in the unsorted sectionO(n²)Learning selection and placement
Arrays.sort()Standard library method for arraysEfficient library implementationSorting arrays in real programs
Collections.sort()Standard library method for listsEfficient library implementationSorting lists in real programs
What does O(n²) mean?
It describes how work grows with the number of items. If the list doubles in size, a quadratic algorithm may do roughly four times the work. This is a growth estimate, not an exact operation count.
Five items

Basic algorithms are small enough to trace by hand.

Thousands of items

Use built-in sorting unless you have a specific reason to implement an algorithm yourself.

One more Java detail: for custom objects, you can sort by a field using a Comparator. Example: students.sort(Comparator.comparing(Student::getName)); assumes the class has a compatible getName() method.

Problem 3 · Find the highest and lowest

Print the smallest and largest values in an integer array.

int[] values = {12, 5, 29, 8, 17}; Arrays.sort(values); System.out.println("Lowest: " + values[0]); System.out.println("Highest: " + values[values.length - 1]);

A single pass that tracks minimum and maximum is more efficient if sorting is not otherwise needed.

Problem 4 · Identify duplicates

For {4, 2, 4, 1, 2, 4}, identify which values repeat after sorting.

After sorting, equal values sit next to one another. Compare each item with the previous item and identify repeated runs. A HashSet is another useful tool for duplicate detection.

Problem 5 · Sort names alphabetically

Sort {"Ravi", "Anu", "Kumar"}.

String[] names = {"Ravi", "Anu", "Kumar"}; Arrays.sort(names); System.out.println(Arrays.toString(names)); // [Anu, Kumar, Ravi]
Problem 6 · Trace bubble sort

For {3, 1, 2}, write down each comparison and swap in the first pass.

Compare 3 and 1, then swap: {1, 3, 2}. Compare 3 and 2, then swap: {1, 2, 3}. The largest value has moved to the end.

Problem 7 · Choose the right method

You have a list of product prices and want cheapest first. Which approach is appropriate?

Use prices.sort(null) or Collections.sort(prices) when the values have a natural order. For product objects, sort with a comparator based on the price field.

Problem 8 · Explain the difference

Explain bubble sort versus selection sort in your own words.

Bubble sort repeatedly compares neighbouring values and swaps them if needed. Selection sort finds the smallest remaining value and places it at the next position.

Key takeaways

  • Bubble sort swaps out-of-order neighbouring values.
  • Selection sort finds the smallest value in the unsorted section.
  • Use Arrays.sort() for arrays and List.sort() or Collections.sort() for lists.
  • Basic sorts are useful for learning; built-in sorting is usually the right practical choice.
