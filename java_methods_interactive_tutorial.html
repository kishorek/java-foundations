1. What is a method?

A method is a named set of instructions that performs a particular task. You can call it whenever you need that task done.

Analogy: a coffee machine
You press the “make coffee” button instead of explaining every step each time. The machine follows its stored instructions. A method works the same way: give the instructions a name, then call that name when needed.
Without a method

Copy and paste the same instructions into many places. Changing them later means editing every copy.

Repeated code
With a method

Write the instructions once and reuse them by calling the method.

Example: greeting someone

static void sayHello() { System.out.println("Hello!"); } // Call the method twice sayHello(); sayHello();

Remember: defining a method describes what it should do. Calling a method asks Java to run those instructions. Defining it alone does not run it.

2. Create and call a method

A basic method has a name, a body, and a return type. A method call uses the name followed by parentheses.

static void sayHello() { System.out.println("Hello, learner!"); } public static void main(String[] args) { sayHello(); // method call }

Read the method from the outside in

1
static

For now, treat this as a way to call the method directly from the class, without creating an object. You will learn objects later.

2
void

The method does not send a value back to the caller. It can still print something or perform an action.

3
sayHello

The method name. Java convention uses lower camel case, for example printReceipt or calculateTotal.

4
() and { }

Parentheses hold parameters. Curly braces contain the instructions that run when called.

Important: in ordinary Java code, a method must be declared inside a class. It cannot be placed directly inside another method.

3. Parameters: give a method information

Parameters are named inputs listed in a method definition. Arguments are the actual values supplied when calling it.

Analogy: ordering a sandwich
The order form has fields such as bread type and filling. Those fields are parameters. Your choices, like “wheat” and “paneer”, are arguments.
static void greet(String name) { System.out.println("Hello, " + name); } greet("Anu"); // argument: "Anu" greet("Ravi"); // argument: "Ravi"

Methods can accept more than one parameter

static void introduce(String name, int age) { System.out.println(name + " is " + age); } introduce("Maya", 14);
The argument order and types must match the method's parameter list. Here, the first argument is a String and the second is an int.

4. Return values: get a result back

A method can calculate or find something and return the result to the code that called it.

Analogy: a vending machine
You choose a product and pay. The machine gives you an item back. A method with a return value gives the caller a result that can be stored, printed, or used in another calculation.
static int add(int a, int b) { return a + b; } int total = add(4, 6); System.out.println(total); // 10

Choose the numbers

The returned result will appear here.

Return type must match the returned value

int

Returns a whole number, such as return 42;

String

Returns text, such as return "Done";

boolean

Returns true or false.

void

Returns no value. Use it for actions that do not need to hand back a result.

Do not confuse these: System.out.println(value) displays a value on the screen. return value; sends a value back to the caller. They are not interchangeable.

What does return do?

When Java reaches a return statement, it sends the result back and exits that method. Statements after that return in the same path do not run.

5. Overloading and local variables

Java lets you create methods with the same name when their parameter lists differ. This is called method overloading.

static int add(int a, int b) { return a + b; } static int add(int a, int b, int c) { return a + b + c; } add(2, 3); // calls the 2-parameter version add(2, 3, 4); // calls the 3-parameter version
Think of a calculator: the name “add” stays the same, but Java can tell which version you want by the number and types of arguments.

Overload explorer

Selected: add(int, int) → 5

Overloading cannot be achieved by changing only the return type. For example, two methods with identical names and parameter types but different return types are not a valid overload.

Local variables live inside their method

static void showScore() { int score = 90; // local variable System.out.println(score); } // score cannot be used here

A local variable belongs to the block where it is declared. Another method cannot directly use that local variable. If another method needs the value, pass it as an argument or return it.

Good method design: use a clear verb phrase such as calculateTax, findMaximum, or printReceipt. Keep each method focused on one job.
