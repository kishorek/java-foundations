Lesson 1

Programs can choose what happens next

A conditional statement runs different code depending on whether a condition is true or false, or depending on a matching value.

🌦️

Imagine checking the weather before leaving home. If it rains, take an umbrella. Otherwise, wear your normal shoes and head out. You are making a decision based on a condition, and Java can follow the same kind of rule.

A simple decision in Java

boolean isRaining = true; if (isRaining) { System.out.println("Take an umbrella!"); } else { System.out.println("Enjoy the weather!"); }

The condition is inside parentheses. Java checks whether it is true, then runs the matching block inside curly braces.

✅

Condition is true

Java runs the statements in the if block.

if (raining)
↪️

Condition is false

If there is an else block, Java runs that instead.

else
Remember: A condition is usually a boolean expression such as age >= 18, score == 100, or a boolean variable such as isRaining.
Lesson 2

if and else: two possible paths

Use if to run code when a condition is true, and else to handle the other case.

🎟️

Think of a cinema ticket checker. If your ticket is valid, you may enter. Otherwise, you need to visit the ticket counter. There are two paths, and the condition decides which one you take.

Interactive ticket gate

if (age >= minimumAge)
Enter the cinema
Runs when the condition is true.
else
Please wait
Runs when the condition is false.
if (age >= minimumAge) { System.out.println("Welcome in!"); } else { System.out.println("Not quite yet."); }
Common mistake: write the condition as age >= minimumAge, with two equals signs as part of the greater than or equal operator. A single = assigns a value rather than comparing values.
Lesson 3

else if: more than two choices

Use an else if chain when the program needs to test several conditions in order.

📚

Imagine a teacher assigning a result based on a score. A high score gets an A, a score in the next range gets a B, and so on. Java checks from top to bottom and runs the first matching branch, so the order matters.

Interactive grade calculator

Enter a score from 0 to 100. Watch which branch becomes active.

if score >= 90
Grade A
else if score >= 80
Grade B
else if score >= 70
Grade C
else if score >= 60
Grade D
else
Needs more practice
if (score >= 90) { grade = "A"; } else if (score >= 80) { grade = "B"; } else if (score >= 70) { grade = "C"; } else if (score >= 60) { grade = "D"; } else { grade = "Needs more practice"; }
Order matters: if you check score >= 60 first, a score of 95 would match that branch and never reach the A condition. Check the most specific or highest threshold first.
Lesson 4

switch: choose from known options

A switch statement is useful when one value can match one of several specific cases, such as a menu choice or day number.

🥤

Think of a vending machine. Press 1 for water, 2 for juice, or 3 for milk. The machine matches your selection to one of its known options. A switch statement can do the same with a value.

Interactive vending machine

Choose a menu number and see which case is selected.

case 3

default
Other choice
switch (choice) { case 1: System.out.println("Water"); break; case 2: System.out.println("Juice"); break; case 3: System.out.println("Milk"); break; default: System.out.println("Choice not available"); }
1
switch (choice)
Java looks at the value in choice.
2
case
Java jumps to the matching case label.
3
break
In the traditional switch statement, break exits the switch so the next case does not run accidentally.
4
default
This branch runs if no case matches.
Modern Java note: Java also supports switch expressions and arrow cases in modern versions. This beginner lesson uses the classic form first because it makes case matching and break easier to understand.
Lesson 5

When should you use if or switch?

Both control program flow, but each is a natural fit for a different kind of decision.

🔎

Use if when

You need to test ranges, combine conditions, or compare different variables.

age >= 18
🎛️

Use switch when

You are matching one expression against specific known values, such as menu options.

case 1, case 2

Which would you choose?

Select a task, then choose the control statement you think is the best fit.

One useful rule: use if for conditions such as greater than, less than, ranges, or multiple boolean checks. Use switch when selecting among discrete, known values is clearer. Both can be correct in some situations, so prefer the clearest readable solution.
